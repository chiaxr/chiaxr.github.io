Projects

PANIC

Play Manual GitHub

A co-op 3D bomb-defusal game inspired by Keep Talking and Nobody Explodes. One player sees the bomb but has no instructions; the other reads the manual but cannot see the bomb, so the only way to defuse the bomb before the timer runs out is to talk it through. Modules are all seeded from the serial number and difficulty so any bomb can be replayed exactly.
